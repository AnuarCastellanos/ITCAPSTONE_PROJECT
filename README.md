# EZTechMovie - StreamList Application
### BSIT Capstone Project | Group 2: Anuar, Shawn, Richard

## Project Purpose
StreamList is a personalized movie streaming management application designed for EZTechMovie subscribers. It allows users to manage their watchlists, select subscription tiers, and securely manage billing information.

## Tech Stack
- **Frontend:** React.js
- **Navigation:** React Router
- **Security:** Integrated masking logic and PCI-compliant UI structures
- **Deployment:** Vercel / GitHub

## Features
- **Authentication:** Secure login simulation.
- **StreamList:** Full CRUD functionality for movie lists.
- **Shopping Cart:** Selection and checkout for Individual, Friendly, and Family plans.
- **Billing:** Secure interface for Credit Card management.
